# PasteLink 使用体验修复计划

**目标：** 修复已有流程中的数据丢失、错误反馈和误操作问题，沿用现有 React/Tauri 与 SwiftUI 界面。

**范围：** Windows 历史收藏与键盘操作、配对码重置确认、设置可访问性和失败提示；iOS 配对保存/解绑、清空确认与图片复制反馈。

**约束：** 保留任务开始前的未提交改动；不改传输协议、UUID、加密格式及安装包；Windows 执行 Cargo 测试和前端构建，iOS 在此 Windows 环境进行 Target 与逻辑静态检查。无可用界面截图通道，本轮不声称完成视觉或真机审查。

- [x] 为 Windows 收藏在容量边界、重复内容和取消收藏时的行为添加回归用例，先验证失败，再修复后端与前端事件合并。
- [x] 修复 Windows 输入法与控件快捷键冲突、选择越界和不可见选择；图片复制失败保持错误状态；设置使用可聚焦开关；重置配对码说明影响并确认。
- [x] iOS 候选 PIN 仅在握手成功后保存，清空绑定不得恢复旧 PIN；输入仅接受 ASCII 数字，验证时禁止重复编辑/关闭。
- [x] iOS 清空历史统一确认与保留收藏提示；图片复制缺失时显示失败，复制成功才显示勾选；发送文案不声称已送达。
- [x] 补充修复检查中发现的图片分享文字错位、相册权限说明缺失与保存结果无反馈；按 Apple 文档使用仅添加权限保存原始 PNG，未增加相册读取权限。
- [x] 执行完整 Rust 测试、前端回归测试及生产构建；检查共享 Swift Target、Intent 签名、UUID 与分片边界；保存质检报告和未验证限制。
